# Release scope

| Component | Status | Evidence / limitation |
|---|---|---|
| Masked probabilities / uniform logger | Implemented example | Explicit synthetic action maps, no learned scores |
| Discovery guard / remaining-cost mask | Implemented example | Caller supplies qualified worst-case bounds |
| Sequential complete-outcome DR | Implemented example | Eq. (10) arithmetic; includes forced-Local branch |
| Paired Unknown endpoints | Implemented example | Direct identification bounds; no confidence coverage claim |
| Registered whole-cohort qualification | Implemented decision only | Frozen nonempty registry/boundary; shared refusal before fit |
| Method-specific technical fallback | Implemented routing only | Pre-evaluation fit/Local selection; no learner or Local executor |
| Existing linear FedAvg numerical worker | Inspected, not redistributed | Legacy baseline, not the paper's learner; license not established |
| Existing MemRL/FedMemRL replication | Not packaged | Historical framework is not current FedMem-VOI |
| Neural actor / local residual / local critics | Absent | No training or cross-fitting implementation claim |
| Federated optimization / personalized heads | Absent | No parameter traffic or local calibration implementation |
| ALFWorld / native benchmark adapters | Absent | No data, rollouts, bank, split or environment supplied |
| Source ontology / permissions / transport | Absent | No qualification or security claim |
| Empirical efficacy / benchmark results | Absent | Synthetic unit tests are not experiments |

No manuscript, artwork, reviews, private records, data, logs, checkpoints,
embeddings, model parameters, task payloads or credentials are in the archive.
